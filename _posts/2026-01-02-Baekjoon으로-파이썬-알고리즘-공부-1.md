## 1. 반복문 - if문

**구구단 (2739번)**
N을 입력받은 뒤, 구구단 N단을 출력하는 프로그램을 작성하시오. 출력 형식에 맞춰서 출력하면 된다.

**입력**
첫째 줄에 N이 주어진다. N은 1보다 크거나 같고, 9보다 작거나 같다.

**출력**
출력형식과 같게 N * 1부터 N * 9까지 출력한다.

**풀이**
{% highlight python %}
n = int(input())
for i in range(9):
    a = n * (i + 1)
    print(f"{n} * {i + 1} = {a}")
{% endhighlight %}

for i in range()의 구조를 사용하는 것이 if문 사용법이다.
구구단의 결과값인 a를 지정하고, 프린트를 할 때 f-string을 사용하면 {} 안에 변수 이름이나 출력하고 싶은 것을 넣으면 된다.


**합 (8393번)**
n이 주어졌을 때, 1부터 n까지 합을 구하는 프로그램을 작성하시오.

**입력**
첫째 줄에 n (1 ≤ n ≤ 10,000)이 주어진다.

**출력**
1부터 n까지 합을 출력한다.

**풀이**
{% highlight python %}
n = int(input())
total = 0
for i in range(1, n + 1):
    total += i
print(total)
{% endhighlight %}

1부터 n+1까지의 범위를 지정한 후, total은 i의 값들을 n+1까지 하나하나 더해 준다고 지정한다.


**영수증 (25304번)**
준원이는 저번 주에 살면서 처음으로 코스트코를 가 봤다. 정말 멋졌다. 그런데, 몇 개 담지도 않았는데 수상하게 높은 금액이 나오는 것이다! 준원이는 영수증을 보면서 정확하게 계산된 것이 맞는지 확인해보려 한다.

영수증에 적힌,

구매한 각 물건의 가격과 개수
구매한 물건들의 총 금액
을 보고, 구매한 물건의 가격과 개수로 계산한 총 금액이 영수증에 적힌 총 금액과 일치하는지 검사해보자.

**입력**
첫째 줄에는 영수증에 적힌 총 금액 
$X$가 주어진다.

둘째 줄에는 영수증에 적힌 구매한 물건의 종류의 수 
$N$이 주어진다.

이후 
$N$개의 줄에는 각 물건의 가격 
$a$와 개수 
$b$가 공백을 사이에 두고 주어진다.

**출력**
구매한 물건의 가격과 개수로 계산한 총 금액이 영수증에 적힌 총 금액과 일치하면 Yes를 출력한다. 일치하지 않는다면 No를 출력한다.

**풀이**
{% highlight python %}
x = int(input())
n = int(input())
total = 0
for i in range(n):
    a, b = map(int, input().split())
    total += a * b
if x == total:
    print("Yes")
else:
    print("No")
{% endhighlight %}

해당 문제는 if, else가 나왔다는 점이 차이점이다.
영수증 총 금액이 일치하는지 알아봐야 하기 때문이 x와 total이 일치할 경우 Yes를 프린트하고, 아닐 경우 No를 프린트하도록 하는 것이다.


**코딩은 체육 과목입니다 (25314번)**
혜아는 long int가 4바이트, long long int가 8바이트라는 책의 내용을 바탕으로, long을 하나 더 붙일 때마다 4바이트씩 더 큰 정수를 저장할 수 있다고 생각했다. 이에 따라 N바이트 크기의 정수를 저장하려면 long을 N/4개만큼 붙이고 마지막에 int를 붙인 정수 자료형을 칠판에 적게 된다. 이 문제는 주어진 N에 대해 혜아가 썼을 정수 자료형의 이름을 그대로 출력하는 것을 묻는다.

**풀이**
{% highlight python %}
n = int(input())
a = n // 4
result = ""
for i in range(a):
    result += "long "
result += "int"
print(result)
{% endhighlight %}

//은 뒤에 적힌 숫자로 나눠진 몫을 의미한다.
즉, result에 a개만큼 "long "을 덧붙이고, 해당 루프에서 마지막에 "int"가 붙도록 result += "int"는 루프 밖에서 씌운다고 볼 수 있다.


**빠른 A+B (15552번)**
for문 문제를 풀 때는 입출력 속도에 특히 주의해야 하며, 느린 입출력 방식은 여러 줄을 처리하는 과정에서 시간 초과를 유발할 수 있다. Python에서는 input() 대신 sys.stdin.readline()을 사용할 수 있는데, 이때 개행 문자가 함께 입력되므로 문자열을 다룰 경우 rstrip()을 사용하는 것이 바람직하다. 또한 입력과 출력은 독립적이므로 모든 테스트케이스를 한꺼번에 저장할 필요 없이, 하나씩 입력받아 바로 출력해도 된다.

**풀이**
{% highlight python %}
import sys

t = int(input())
for i in range(t):
    a, b = map(int, sys.stdin.readline().split())
    result = a + b
    print(result)
{% endhighlight %}

input() 함수는 개행문자 /n을 떼고 출력하는 등 계산 과정이 추가되어 문자열 반환이 더 느려지는 반면, sys.stdin.readline()은 추가 가공이 없어 문자열 반환이 빨라진다.


**별 찍기 - 1 (2438번)**
첫째 줄에는 별 1개, 둘째 줄에는 별 2개, N번째 줄에는 별 N개를 찍는 문제

**풀이**
{% highlight python %}
n = int(input())
for i in range(n):
    print("*"*(i+1))
{% endhighlight %}

print()에서 "*"에 숫자를 곱하면 그만큼 출력이 된다.



## 2. 반복문 - while문

**A+B - 5 (10952번)**
두 정수 A와 B를 입력받은 다음, A+B를 출력하는 프로그램을 작성하시오.

**입력**
입력은 여러 개의 테스트 케이스로 이루어져 있다. 각 테스트 케이스는 한 줄로 이루어져 있으며, 각 줄에 A와 B가 주어진다. (0 < A, B < 10) 입력의 마지막에는 0 두 개가 들어온다.

**출력**
각 테스트 케이스마다 A+B를 출력한다.

**풀이**
{% highlight python %}
while True:
    a, b = map(int, input().split())
    if (a+b) == 0:
        break
    print(a+b)
{% endhighlight %}

while 조건: 형태로 쓰고, if 조건: break를 하면 while문의 루프를 if 조건일 때 종료할 수 있다.


**A+B - 4 (10951번)**
두 정수 A와 B를 입력받은 다음, A+B를 출력하는 프로그램을 작성하시오.

**입력**
입력은 여러 개의 테스트 케이스로 이루어져 있다. 각 테스트 케이스는 한 줄로 이루어져 있으며, 각 줄에 A와 B가 주어진다. (0 < A, B < 10)

**출력**
각 테스트 케이스마다 A+B를 출력한다.

**풀이**
{% highlight python %}
import sys

input_str = sys.stdin.readline()

while input_str !="":
    a, b = map(int, input_str.split())
    print(a+b)
    input_str = sys.stdin.readline()
{% endhighlight %}

변수가 공백이 아닐 때 while 루프가 계속 돌아가게 하는 것이다. 여기서 input_str = sys.stdin.readline()을 마지막 줄에 넣어 input_str에 공백이 아닌 들어오는 게 있을 때 루프가 계속 돌아가게끔 해 주는 것인데, input() 대신 sys.stdin.readline()을 사용해 테스트 케이스가 늘어날 경우 런타임 에러가 나지 않도록 해 준다.
또한, EOF 처리에 유리하다.
sys.stdin.readline() → EOF에서 "" 반환
input() → EOF에서 EOFError 발생 (try-except 필요)
